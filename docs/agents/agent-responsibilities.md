# Agent Responsibilities

## Core specialist agents

- **Blockchain Builder**: Solidity and protocol implementation support.
- **Web3 Research Orchestrator**: Exa-first protocol and ecosystem intelligence.
- **Dev Forge**: backend/frontend integration and delivery workflows.
- **Telegram Ops Agent**: handles full Telegram process automation (ingress, routing, and response delivery).

## Supervisor principle

Use a supervisor to route tasks across specialists, merge outputs, and enforce validation gates before responses are emitted.
