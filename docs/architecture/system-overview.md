# System Overview

Fully AI Stack is an AI-native Ethereum engineering platform built around an Exa-first research strategy and a LangGraph-supervised execution flow.

## Platform goals

- Provide a unified control center for specialist Ethereum agents.
- Keep research and engineering loops observable from one dashboard.
- Support channel-driven execution, including Telegram, for real-world operations.

## Repository layout

- `backend/`: FastAPI API layer, agent orchestration surface, and LangGraph placeholders.
- `frontend/`: Next.js TypeScript dashboard with a dark, sidebar-first control-center layout.
- `docs/`: architecture, agent, and integration references.
- `infra/`: local development placeholders for Docker and helper scripts.

## Exa-first pattern

Research-heavy workflows start with externally sourced evidence (Exa pattern), then pass curated findings to planning and build agents. This keeps Ethereum outputs current and verifiable.
